# 📚 Library Management System

Aplikasi manajemen perpustakaan berbasis web untuk mengelola data buku, anggota, dan transaksi peminjaman buku secara digital.

## 📝 Deskripsi Aplikasi

Library Management System adalah aplikasi web full-stack yang membantu proses pengelolaan perpustakaan, mulai dari pendataan buku dan anggota, hingga pencatatan transaksi peminjaman dan pengembalian buku. Aplikasi ini dilengkapi dashboard statistik, fitur pencarian & filter, dark mode, export data ke CSV, dan upload gambar sampul buku.

## 🛠️ Teknologi yang Digunakan

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** Node.js, Express.js
- **Database:** MySQL (XAMPP/phpMyAdmin)
- **Lainnya:** REST API, Fetch API, Multer (upload gambar)

## ✨ Fitur Utama

- CRUD lengkap untuk **Buku** dan **Anggota**
- Transaksi **Peminjaman** dengan update stok otomatis
- Dashboard statistik (total buku, anggota, buku dipinjam/dikembalikan)
- Search & Filter data buku dan anggota
- Upload gambar sampul buku
- Export data buku ke CSV
- Dark Mode
- Toast notification & loading spinner
- Responsive layout (mobile-friendly)
- Validasi input (field wajib, format email, dll)
